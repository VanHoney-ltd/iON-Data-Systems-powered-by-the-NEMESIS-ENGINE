Wails Frontend User Manual

This manual explains how to start the Wails frontend for the Ion project.

Prerequisites

  • Node.js and npm installed (for frontend dependencies)
  • Go installed (for the Wails backend)
  • Wails CLI installed (version 2.12.0 or compatible)

Project Structure

The project is located at: /home/ghost/iON/ion

  • /home/ghost/iON/ion/frontend - Contains the Svelte frontend
  • /home/ghost/iON/ion/main.go - Main Go application
  • /home/ghost/iON/ion/wails.json - Wails configuration

Steps to Start the Frontend

Step 1: Navigate to the Project Directory

Open a terminal and change to the project directory:

cd /home/ghost/iON/ion

Step 2: Install Frontend Dependencies (if not already installed)

The first time you set up the project, you need to install the frontend dependencies:

cd frontend && npm install

After installation, return to the project root:

cd ..
Note: If you see a warning about deprecated packages or vulnerabilities, you can usually ignore them for development. To fix vulnerabilities, you can run npm audit fix in the frontend directory.

Step 3: Start the Wails Development Server

Run the Wails development command to start both the Go backend and the frontend dev server:

wails dev

You should see output similar to:

[0;92mWails CLI[0m [0;31mv2.12.0[0m [0;92mExecuting: go mod tidy[0m ... [0;92mVite Server URL: http://localhost:5173/[0m ... [0;92mRunning frontend DevWatcher command: 'npm run dev'[0m ... [0;92mUsing DevServer URL: http://localhost:34115[0m [0;92mUsing Frontend DevServer URL: http://localhost:5173/[0m ... [0;92mTo develop in the browser and call your bound Go methods from Javascript, navigate to: http://localhost:34115[0m

Step 4: Access the Application

Once the development server is running, you can access the application in your web browser:

  • Wails Application (with Go backend): http://localhost:34115
  • Frontend Dev Server (for hot reload): http://localhost:5173/
Note: The Wails application (localhost:34115) is the main interface that connects to your Go backend. The frontend dev server (localhost:5173) provides hot module replacement for faster development.

Stopping the Development Server

To stop the Wails development server, press Ctrl + C in the terminal where the command is running.

Troubleshooting

  • Port already in use: If you get an error about ports 5173 or 34115 being in use, stop any existing processes or change the ports in the configuration.
  • Dependencies not found: Make sure you ran npm install in the frontend directory.
  • Wails command not found: Ensure the Wails CLI is installed and in your PATH. You can install it with go install github.com/wailsapp/wails/v2@latest.

Additional Information
