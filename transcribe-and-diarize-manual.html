iON Transcribe & Diarize Manual

This guide covers the complete workflow for converting case video/audio into time-stamped, speaker-labeled transcripts using OpenAI Whisper and pyannote.audio.

Goal: Take any case media file (MP4, MOV, etc.) and produce a transcript that identifies who spoke when and what they said.

Prerequisites

  • Python 3.8–3.12 installed (3.14 may lack PyTorch wheels)
  • ffmpeg installed system-wide
  • Hugging Face account + access token
  • GPU recommended (AMD ROCm or NVIDIA CUDA). CPU works but is slow.
Fish Shell Users: The standard source venv/bin/activate is for Bash/Zsh. In Fish, use source venv/bin/activate.fish or run everything inside a Bash subshell: bash.

Workflow Overview

  1. Extract clean audio from video with ffmpeg
  2. Create and activate a Python virtual environment
  3. Install Python dependencies
  4. Authenticate with Hugging Face
  5. Run Whisper transcription
  6. Run pyannote speaker diarization
  7. Align transcripts to speakers (optional advanced step)

Detailed Steps

1Extract Audio from Video

Convert the case video to a single-channel 16kHz WAV. This format is ideal for both Whisper and pyannote.

ffmpeg -i input_video.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 output_audio.wav
-vnDiscard video stream
-acodec pcm_s16le16-bit PCM (lossless)
-ar 1600016 kHz sample rate (required by Whisper)
-ac 1Mono (single channel)

2Create a Virtual Environment

python3 -m venv transcribe-env

Activate it (choose your shell):

# Bash / Zsh
source transcribe-env/bin/activate

# Fish
source transcribe-env/bin/activate.fish

3Install Dependencies

# Upgrade pip first
pip install --upgrade pip

# PyTorch (CPU build shown; swap for ROCm/CUDA if you have a GPU)
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu

# Core transcription & diarization libraries
pip install pyannote.audio
pip install openai-whisper

# Hugging Face CLI (for authentication)
pip install huggingface-hub
AMD GPU: Replace the PyTorch line with the ROCm wheel:
pip install torch torchaudio --index-url https://download.pytorch.org/whl/rocm6.2

4Authenticate with Hugging Face

pyannote models require a Hugging Face token and acceptance of the model license.

  1. Sign up / log in at huggingface.co
  2. Visit pyannote/speaker-diarization-3.1 and accept the user agreement
  3. Visit pyannote/segmentation-3.0 and accept the user agreement (required dependency)
  4. Visit pyannote/speaker-diarization-community-1 and accept the user agreement (required dependency)
  5. Generate an access token at Settings → Access Tokens

Then run:

hf auth login

Note: huggingface-cli is deprecated. Use hf instead.

Paste your token when prompted.

5Transcribe with Whisper

Load a Whisper model and transcribe the extracted WAV.

import whisper

model = whisper.load_model("base")  # tiny | base | small | medium | large
result = model.transcribe("output_audio.wav")

for segment in result["segments"]:
    start = segment["start"]
    end   = segment["end"]
    text  = segment["text"].strip()
    print(f"[{start:>7.2f} - {end:>7.2f}] {text}")
Model Sizes:
tiny = fastest, least accurate  |  base = good for quick tests  |  large = best accuracy, slowest, needs >10 GB VRAM

6Diarize with pyannote

Identify speaker turns (who spoke when).

from pyannote.audio import Pipeline

pipeline = Pipeline.from_pretrained(
    "pyannote/speaker-diarization-3.1"
)

diarization_output = pipeline("output_audio.wav")
diarization = diarization_output.speaker_diarization

for turn, _, speaker in diarization.itertracks(yield_label=True):
    print(f"Speaker {speaker}: {turn.start:.1f}s - {turn.end:.1f}s")

7Align Transcripts to Speakers (Optional)

Combine Whisper word-level timestamps with pyannote speaker segments to label each sentence with a speaker.

def get_speaker_at_time(timestamp, diarization):
    for turn, _, speaker in diarization.itertracks(yield_label=True):
        if turn.start <= timestamp <= turn.end:
            return speaker
    return "UNKNOWN"

for segment in result["segments"]:
    t = (segment["start"] + segment["end"]) / 2
    speaker = get_speaker_at_time(t, diarization)
    print(f"[{speaker}] {segment['text'].strip()}")
For production-grade alignment consider WhisperX or faster-whisper with word timestamps, which make mapping words to speaker segments much more precise.

Full Example Script

Save this as transcribe_diarize.py and run it inside the activated environment:

#!/usr/bin/env python3
import whisper
from pyannote.audio import Pipeline

AUDIO_FILE = "output_audio.wav"

def main():
    # 1. Transcribe
    print("Loading Whisper model...")
    model = whisper.load_model("base")
    result = model.transcribe(AUDIO_FILE)

    # 2. Diarize
    print("Loading pyannote pipeline...")
    pipeline = Pipeline.from_pretrained(
        "pyannote/speaker-diarization-3.1"
    )
    diarization = pipeline(AUDIO_FILE)

    # 3. Simple speaker alignment
    def speaker_at(t):
        for turn, _, spk in diarization.itertracks(yield_label=True):
            if turn.start <= t <= turn.end:
                return spk
        return "UNKNOWN"

    print("\n--- TRANSCRIPT ---\n")
    for seg in result["segments"]:
        t = (seg["start"] + seg["end"]) / 2
        spk = speaker_at(t)
        print(f"[{seg['start']:>7.2f}s - {seg['end']:>7.2f}s] {spk}: {seg['text'].strip()}")

if __name__ == "__main__":
    main()

Output Format

Typical console output looks like:

[   0.00s -    3.24s] SPEAKER_00: My name is Cody Redmond.
[   3.40s -    7.10s] SPEAKER_01: Can you state the date for the record?
[   7.20s -   10.55s] SPEAKER_00: Today is October first, twenty twenty-five.

Troubleshooting

torch install fails Your Python version may be too new (3.14). Install Python 3.11 via pyenv or mise and recreate the venv.
HF 403 error You have not accepted the pyannote model license on Hugging Face. Visit the model page and click "Access repository".
Out of memory Use a smaller Whisper model (tiny or base) or run on CPU by setting DEVICE = "cpu".
Diarization poor quality Ensure audio is mono 16kHz. Crosstalk and heavy background noise reduce accuracy.

Hermes Agent — Automated Media Catalog & Transcription

Hermes is the iON agent responsible for collecting media metadata, building a unified catalog, and conditionally running transcription and speaker diarization based on assigned investigation contacts.

Hermes runs after Charon and consumes evidence from:

  • Charon — photos, videos, screen recordings, live photos
  • Echo — voicemail and audio recordings
  • Cerberus — MMS/SMS attachments with linked contacts

When Transcription Runs

Transcription and diarization are disabled by default. They only activate when a case has contacts (phone numbers) assigned for investigation via the case registry.

When active, Hermes transcribes only media linked to those contacts:

  • Voicemail from the target phone number(s)
  • MMS audio/video attachments sent to/from the target number(s)
  • Camera/screen recordings are cataloged but not auto-transcribed unless explicitly matched to a contact

Running Hermes

minios hermes <case_name>

Example:

minios hermes pcr

Outputs

All files are written to evidence/hermes/ inside the case directory:

records.json Evidence records in iON unified format
media_catalog.json Complete media inventory with metadata, thumbnails, dates, sources
media_catalog.pdf Printable catalog report with emoji thumbnails and transcription status
transcripts/<item_id>/ Per-item transcription output (JSON, merged text, diarization, PDF)

Assigning Investigation Contacts

Contacts are managed through the case registry. Hermes reads the phone_numbers list from ~/.iON/case_registry.json.

// Example registry entry for case "pcr"
{
  "cases": {
    "pcr": {
      "root": "/home/ghost/iON/cases/pcr",
      "phone_numbers": ["15152038573", "15159967300"],
      "contacts": {},
      "device_phone_number": "5155555555"
    }
  }
}

When phone_numbers is empty, Hermes builds the catalog but skips transcription. When populated, only media matching those numbers is processed.

Exporting to PDF

To export the merged transcript to a printable PDF report using LibreOffice:

  1. Generate a styled HTML report from the merged transcript
  2. Convert with LibreOffice headless mode:
libreoffice --headless --convert-to pdf --outdir output_dir/ report.html

A sample Python script for generating the HTML report is included in the iON toolkit (generate_pdf.py).
